# Triage Preferences

Triage reads this file before every run and applies what it says without
asking again. It holds my process defaults: where captures go, how dates and
links are written, what order to work in. How email is classified belongs in
sift-email's rubric, not here. Keep it under about a page.

## How to use this file

- **Change a default:** edit any line. The next run follows it.
- **Add one mid-run:** say it in the conversation ("cards go to the top of
  Backlog"). Triage applies it for the rest of that run and offers to add it
  here, in the section it belongs to.
- **Override once:** say so in the conversation. A default stated in a run
  wins over this file for that run only.
- **Leave a section empty** to have triage ask, or use its own default.
