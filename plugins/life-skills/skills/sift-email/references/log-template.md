# Email Sift Log

What sift did on each run, newest first, so I can check any call. To correct
one, change its label in Gmail (see the rubric's "How to use this doc").

## Runs

Each run adds its date and time, a short summary, then one line per thread:

time | thread id | sender | subject | labels applied | reason

Times are in the timezone the rubric names.

## Weekly summaries

Runs older than 30 days, rolled up to one line per week.
