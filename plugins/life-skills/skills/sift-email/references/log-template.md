# Email Sift Log

What sift did on each run, newest first, so I can check any call. To correct
sift, edit the rubric (see its "How to use this doc").

## Runs

Each run adds its date, time, and start in epoch seconds, a short summary,
then one line per thread:

time | thread id | sender | subject | applied | reason

The first run each day also adds a "Daily review" line, and an "observed"
line for each sign of how I handled a thread sift labeled.

Times are in the timezone the rubric names.

## Weekly summaries

Runs older than 30 days, rolled up to one line per week.
