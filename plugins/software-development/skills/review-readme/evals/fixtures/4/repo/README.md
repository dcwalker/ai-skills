# Pingpong

A minimal HTTP server that responds `pong` to every request.

## Prerequisites

- Node.js >= 20

## Installation

```bash
npm install
```

## Usage

Start the server:

```bash
npm run dev
```

The server listens on port 4000.

## Testing

```bash
npm test
```

## Linting

```bash
npm run lint
```
