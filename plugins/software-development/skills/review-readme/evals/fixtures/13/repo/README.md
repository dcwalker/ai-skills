# Treeview

A small demo app used to test directory tree verification.

## Project Structure

```
treeview/
├── server.js
├── src/
│   ├── controllers/
│   │   └── userController.js
│   └── utils/
│       └── helpers.js
└── package.json
```

## Installation

```bash
npm install
```

## Usage

```bash
npm run dev
```

## Testing

```bash
npm test
```
