# Plan Weekly Review

Guide a structured weekly review that ends with a short, prioritized plan.

## Step 1: Gather inputs

Ask the user for their open commitments: calendar highlights for the coming
week, any task list or backlog they keep, and anything nagging at them that
is not written down anywhere yet.

## Step 2: Review the past week

Walk through what was planned versus what happened. Capture wins, misses,
and anything that should carry forward. Do not assign blame; the goal is an
accurate picture, not a judgment.

## Step 3: Prioritize the coming week

Have the user pick at most three priorities for the week. Everything else is
explicitly deferred. If the user proposes more than three, ask which they
would drop if the week went sideways.

## Step 4: Produce the plan

Write a short plan: the three priorities, each with a concrete first action,
plus a parking list of deferred items. Confirm the user is happy with it
before finishing.

## Rules

- Never invent commitments the user did not mention.
- Keep the final plan under one page.
